Cyclic Core Covering and Finite Cubical Cell Complexes

Alan J. Coppola (coppolaa@evergreen.edu) and Richard Weiss (weissr@evergreen.edu)

The Evergreen State College

Olympia, WA 98505-0002

Abstract

In this paper, we improve the standard branch-and-bound algorithm for finding a minimum cover by addressing the cyclic-core processing. We show how a covering problem such as two-level logic minimization can be represented as a finite cubical cell complex, which encodes topological information that aids the minimization process. The paper shows that by extending the covering table so that it also represents the implicitly defined combinatorial finite cubical cell complex of a covering problem, any resulting cyclic-core covering sub-problems, with collapsible cells, can be exactly solved using only one recursive call instead of two. The new covering table operation, called collapse, arises from the concepts of cell collapse and expansion from simple homotopy theory in topolgy. A collapsible cell of the cyclic core allows the two recursive calls (cell-in and cell-out) to be encoded into one call. This reduces the number of recursive computations needed to solve the minimal covering problem.

1 Introduction

Covering problems are typically solved using branch and bound algorithms, by realizing them in tabular form, followed by iterative reduction of the table by removing columns and rows through a small set of fixed operations. This process terminates when all of the rows have been eliminated indicating that all of the cells have been covered. The columns correspond to prime implicants and the ones that have been removed in this process form the minimal cover. However, the operations that are usually applied can result in a situation called a cyclic core, where the problem is split into two subproblems of equal size and each one is solved independently. Our goal is to create an operation which produces a single subproblem that is roughly the same size as each of the other subproblems, and thus, we cut the amount of computation for that step in half.

The standard table operations that are used to produce the minimal cover are essentiality, row dominance, column dominance and Gimpel's transform. [2] They depend on finding essential prime implicants, followed by row and column reductions. An essential prime implicant contains a min-term that is not covered by any other prime implicant. A fixed-point occurs if the operations do not change the table after each application even though the algorithm has not terminated. This occurs when there are no essential prime implicants, or dominated elements, and the configuration is called a cyclic core. The step that is usually applied is to choose a column (prime implicant) and generate two instances of the problem: one in which the prime implicant is part of the minimal cover, and one in which it is not. Each of these subproblems can then be solved recursively using the branch and bound method with the standard table operations.

Our approach is based on the intuition that the table representation is omitting information that is present in the cube complex, which is a natural representation of the original two-level logic minimization problem. The cube complex is a set of cubes of various dimensions with the property that if they intersect, then the intersect in a set of faces which are also cubes. All of these cubes can be viewed as subsets of a cube whose dimension is the number of variables in the logical expression to be minimized. [1], [5]

Most recent work on the covering problems have attacked finding and applying the lower bounds found to prune the search space for the minimal solution. [6-9] This paper introduces a different method for pruning the search space, based on an encoding used for special cells in the cyclic core. The identification and of these cells allows one recursive call instead of two to solve a cyclic core subproblem. This is our contribution.

We prove a theorem which shows that given the cyclic-core of a minimization problem, there is a special type of cube, a collapsible cube, to branch on, such that the minimum cover can be found with a single recursive call. We present an example of a cubical cell complex representation, and corresponding minimization.

2 Definitions and Background

2.1 Cubical Cell Complexes, Combinatorial Topology, and Covering

The cubical cell complex provides a general framework in which to represent minimal covering problems, higher-order connectivity, cycles of any dimension, and geometric visualization of optimization problems.

For the purposes of this paper, we specialize to cubes and cubical complexes, even though the techniques can be generalized to cells and abstract cell complexes.

  • A collection of cubes Skel of B k , each of which is called a cube of C, and a partial order ≤, which captures the face relations of C.

  • A face closure property for Skel (if a ε Skel, and b ≤ a then b ϵ Skel )

Definition 2.
L is a sub-complex of K if L is a cubical complex, each of whose faces are faces of K. For example, if Li = { c ε Skel | dim(c)⩽ i }, then Li is the sub-complex called the i-skeleton of C.

Definition 3.
Let C be a cubical cell complex. Let c be a cell of C. c is said to be collapsible if c has a face f ≤ c, such that dim(f) = dim(c) - 1, and f is not a face of q, for all q ε C. f is also called a free face of c.

The concept of cellular collapses and expansions comes from simple homotopy theory of topology. In this context it also captures a generalization of essential prime because for a cell to be collapsible, it must have a free face, i.e. one that is not shared. [4], [5]

Definition 4.
If K and L are cubical cell complexes, we say that there is an elementary cell collapse from K to L (K↘L), if K = L ∪ e, where e is a cell of K, with free face f not a face of any other face of L. The cell e is said to be a collapsible cell. Note: This is equivalent to the existence of a homotopy from K to L. Also, L is said to expand to K (L↗K).

3 Minimization Process

3.1 Exact Two-Level Boolean Minimization [2]

The object of this classical problem is given a boolean function f, find an exact minimum size representation of f as a sum-of-products cube representation of f. The usual method is:

Theorem 5. Given a sum-of-products boolean function f, the minimum cost representation of f as a sum of products is found by iteratively applying steps 1-4.

  1. [FindPrimes ] Find all the prime implicants of f
  2. [CreateCov] Create the covering matrix of the primes of f, where the columns are the primes and the rows are the minterms of f.

  3. [Reduction] Perform reductions on the covering matrix, until a fixed point table, called the cyclic-core is reached. The table reductions are: [2],[3]

    1. Partitioning (i.e. finding the conected components), iteratively followed by:

      • Essentials reduction by choosing cubes which are essentials to be in the minimal cost cover.
      • Row dominance - a strongly equivalent operation (no solutions are eliminated [2])

      • Column dominance - a weakly equivalent operation (some solutions are eliminated, but a minimum is not [2])

  4. [SolveCyclicCore] Recursively solve the cyclic-core problem by choosing a column(prime) to assume is first in the cover, find a recursive solution, and then is not in the cover, find a recursive solution to that problem, and then pick the cover that has the least number of elements as the minimal cover. Sophisticated branch and bound techniques, involving choosing a maximal independent set of elements at each cyclic-core step which can be used to create a series of lower bounds on which to prune the recursions. See [6],[7],[8],[9].

    The method we propose will enhance Step 4, by allowing a single recursive call in the case that a free face is found.

3.2 Cyclic Core Reduction Overview

We assume that the cell complex is represented either explicitly or implicitly, and that no computation of faces or intersections are explicity done unless needed. i.e. lazy evaluation is used. For example, an explicit initial representation would be a list of cubes of varying dimensions. An implicit representation would be as a BDD.

During the exact minimization algorithm outlined in Section 3.2, the list of cubes can grow and shrink. We assume that the prime cube complex is given, and that the covering table is replaced by a choice pairing function Pairf(cube, prime) = 1 ⇔ cube⩽prime . This allows us to view a covering table a view of the cubical complex. No face information is lost. This is key in allowing us to compute the collapsible cubes necessary to reduce the cyclic core resursively.

4 Description of Algorithm

Let P(C) represent the prime complex of a two-level minimization problem, initially given as a cubical complex C, let TP(C) be the graded (by dimension) covering table representing the choice pairing function Pairf(cube, prime) by a (∑ni) x |P| matrix of 0's and 1's, where P is the cubical complex of all prime cubes of C, and ni is the number of covering element cubes in the cover of dimension i. In the classical Quine-McCluskey case, n0=number of vertices(minterms) of C(f).

Each cube will correspond to a row of the covering table, and each column corresponds to a prime cube of the cubical complex, which lives in a universe which is the smallest dimensional cube containing all the cubes of the cubical complex.

The graded table is a view of the cubical cell complex and can be derived from it. Restated, the minimal covering problem is to find a set of columns of TC which cover C, and has minimal cost. The contribution of this paper is two-fold: to use the cubical cell complex directly as the representation of the combinatorial minimization problem, and to show how this representation allows the introduction of a new reduction method during the cyclic core recursive solution.

The covering problem is to find a minimum set of columns of TC which cover C, and has minimal cost.

The new contribution of this paper is two-fold: to introduce cell complexes as a natural representation of combinatorial problems, and to show how this representation allows the introduction of a new reduction method during the cyclic-core recursive solution.

4.1 Finding a collapsible cell.

With the representation we have chosen, finding collapsible cubes is like finding essential cubes. Consider a top dimensional cell c, of dimension k. Then a cube with a free face is one where the set of k-dimensional cubes other than c intersected with c does not cover the faces of c. The faces of c not covered by these k-dimensional cells are the free faces. Note that the analogous step for essential primes is the first step in the classical Quine-McCluskey algorithm.

4.2 Collapsible Element Reduction

Given an implicit or explicit representation of the initial cubical complex, we allow the addition of cells to the complex, when necessary, to solve the covering problem. Most additions result from intersecting cells when computing the set of primes or in finding the collapsible cells.

Theorem 6. The [CyclicCore] step of Theorem 5 can be replaced by the [CyclicCoreCollapse] step, and maintain cover cost minimality.

[CyclicCoreCollapse] If a collapsible element exists, removing the element p, and replace it with the set of free faces of p, perform a single recursive call of the modified minimization algorithm, if any of the added faces are in the returned cover, remove them, and add p back in. If there are no collapsible faces, perform the [CyclicCore] step of Theorem 5. So the Theorem 5 usual algorithm is not modified unless there are collapsible cells, in which case columns are temporarily removed and added during the course of the minimization.

Proof

□

This involves, at the graded covering matrix level, removing the column p, and replacing it with a set of one dimensional less columns which are the free faces of p, FreeFaces(p).

Recursively continue to apply the non cyclic-core reductions, followed by the cyclic-core collapsible reduction, along with chosing a face of the the most recently used collapsible cube processed when a sub cyclic core has no collapsible cubes in it, and return with a cover CollapseCov.

Claim: CollapseCov, or CollapseCovPlus = ReducedCov(CollapseCov + p) is the absolute minimum cost cover of the row elements by the column sets, where ReducedCov simply takes a cover and makes it irredundant.

Let FreeSize = |CollapseCov ∧FreeFaces(p)|. To complete the proof, consider the following cases:

  1. FreeSize = 0 ,

    If FreeSize = 0 , then CollapseCov is the minimum, as it didn't use any of the added free face cells, hence only used the original cells to cover the rows, and, so corresponds to the case that the collapsible cube was not included initially, whereas, by including the free faces, the opportunity was presented to the minimization algorithm to use them to get a solution with lesser cost, so if a cover of lesser cost existed with some of the free faces of p in it, then it would have been found.

  2. FreeSize ⩾ 1,

    Then CollapseCovPlus is the minimum, as the expansion of the cube in the direction of one of the free faces returned keeps the cost the same, or better, if the cost function is dimension dependent. Then CollapseCovPlus is the minimum, and will have a cost less than or equal to the cost of CollapseCov, as if all the returned faces are removed, we have a minimum cover of the original Cyclic Core by primes, which can be at most one less element in cost from the case when the cube is originally included in the minimal cover, and then minimized. This returned encoding corresponds to having the original cube p in the minimal cover.

5 Realization Considerations

State of the art unate covering tools are embodied in the tools Eclipse, Aura-II, Scherzo, and Espresso-Signature-Exact. [2, 6-9] To implement the concepts in this paper, the techniques should be added to one of the above code bases, and compared to the others on suites of examples, as was done in Eclipse and Aura-II.

It is an open question as to whether the proof given in this paper can be extended to the case of encoding all of the collapsible cubes simultaneously, as a single step, and then continuing with the algorithm recursively. This type of operation would correspond to shelling the cyclic core by collapsing it's boundary all at once, and then recursively continuing with that process.

6 Conclusions and Future Work

In this paper, it was shown first, how to identify special cubes, called collapsible ones, in the cyclic core covering problem, and second how to use them to modify the branch part of the branch and bound algorithm, which allows a minimum cost solution to be found with a single recursion, at the cost of encoding the collapsible cubes by their free faces, and by maintaining the structure of the cubical cell complex, as the minimization proceeds.

In future work, we plan to generalize the current approach for cubical cell complexes. We believe that binate covering problems, MaxCostSAT and other problem areas can also be addressed using these methods.

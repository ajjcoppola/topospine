Cyclic Core Covering and Finite Cubical Cell Complexes

Alan J. Coppola and Richard Weiss

The Evergreen State College

Olympia, WA 98505-0002

Abstract

In this paper, we improve the standard branch-and-bound algorithm for finding a minimum cover by addressing the cyclic-core processing. We show how a covering problem such as two-level logic minimization can be represented as a finite cubical cell complex, which encodes topological information that aids the minimization process. The paper shows that by extending the covering table so that it also represents the implicitly defined combinatorial finite cubical cell complex of a covering problem, any resulting cyclic-core covering sub-problems, with collapsible cells, can be exactly solved using only one recursive call instead of two. The new covering table operation, called collapse, arises from the concepts of cell collapse and expansion from simple homotopy theory in topolgy. A collapsible cell of the cyclic core allows the two recursive calls (cell-in and cell-out) to be encoded into one call. This reduces the number of recursive computations needed to solve the minimal covering problem. Connections to Unate Covering Problems(UCP), Binate Covering Problems (BCP), and MaxCostSAT are given.

1 Introduction

Covering problems are typically solved using branch and bound algorithms, by realizing them in table form, followed by iterative reduction of the table by reduction operations which leave a fixed -point subproblem, called the cyclic core, which is then solved recursively.

Most work on minimal covering problems has focussed on operations involving the covering table. Essentiality, row dominance, column dominance and Gimpel's transform. Once a fixed-point of these operations is reached, the resulting sub problem, typically called the cyclic core, is solved by recursively by chosing a column to recurse on, using the branch and bound method , where the problem assumes the corresponding prime implicant is either in the minimal cover or not.



The two-level logic exact minimization problem has a natural representation as an array of cubes of various dimensions. When looking at the resulting representation of a cyclic core, it was noticed that it was not truly cyclic as a chain, but had a number of free/boundary faces, which could be collapsed. By carrying along the face structure with the covering problem, we show that a free face does allow a reduction in the number of recursive calls to the branch and bound algorithm.

Most recent work on the covering problems have attacked finding and applying the lower bounds found to prune the search space for the minimal solution. This paper introduces a different method for pruning the search space, based on an encoding used for special cells in the cyclic core. The identification and of these cells allows one recursive call instead of two to solve a cyclic core subproblem. This is our contribution.

We prove a theorem which shows that given the cyclic-core of a minimization problem, there is a special type of cube, a collapsible cube, to branch on, such that the minimum cover can be found with a single recursive call. We present an example of a cubical cell complex representation, and corresponding minimization.

2 Definitions and Background

2.1 Cubical Cell Complexes, Combinatorial Topology, and Covering

An cubical cell complex generalizes the representation of a structure in which to represent minimal covering problems, higher-order connectivity, cycles of any dimension, and geometric visualization of optimization problems.

For the purposes of this paper, we specialize to cubes and cubical complexes, even though the techniques can be generalized to cells and abstract cell complexes.

3 Minimization Process

3.1 Restrictions

For the purposes of this paper, we will restrict ourselves to considering the Exact Two-Level Boolean Minimization problem. The techniques presented here can be extended to an abstract cell complex, with a universe complex in a straightforward mannner.

3.2 Exact Two-Level Boolean Minimization

The object of this classical problem is given a boolean function f, find an exact minimum size representation of f as a sum-of-products cube representation of f. The usual method is:

Theorem 6. Given a sum-of-products boolean function f, the minimum cost representation of f as a sum of products is found by iteratively applying steps 1-4.

  1. [FindPrimes ] Find all the prime implicants of f
  2. [CreateCov] Create the covering matrix of the primes of f, where the columns are the primes and the rows are the minterms of f.

  3. [Reduction] Perform reductions on the covering matrix, until a fixed point table, called the cyclic-core is reached. The table reductions are: [Courdert2]]

    1. Partitioning (i.e. finding the conected components), iteratively followed by:

      • Essentials reduction
      • Row dominance - a strongly equivalent operation

      • Column dominance - a weakly equivalent operation

  4. [SolveCyclicCore] Recursively solve the cyclic-core problem by choosing a column(prime) to assume is first in the cover, find a recursive solution, and then is not in the cover, find a recursive solution to that problem, and then pick the cover that has the least number of elements as the minimal cover. Sophisticated branch and bound techniques, involving choosing a maximal independent set of elements at each cyclic-core recursion which can be used to create a series of lower bounds on which to prune the recursions. See [Courdert], [Goldberg], [Xing-Berlez].

    The method we propose will enhance Step 4, by allowing a single recursive call in the case that a free face is found.

3.3 Cyclic Core Reduction Overview

We assume that the cell complex is represented either explicitly or implicitly, and that no computation of faces or intersections are explicity done unless needed. i.e. lazy evaluation is used. For example, an explicit initial representation would be a list of cubes of varying dimensions. An implicit representation would be as a BDD. [Swany]

During the exact minimization algorithm outlined in Section 3.2, the list of cubes can grow and shrink. We assume that the prime cube complex is given, and that the covering table is replaced by a choice pairing function function Pairf(cube, prime) = 1 ⇔ cube⩽prime . This allows us to view a covering table a view of the cubical complex. No face information is lost. This is key in allowing us to compute the collapsible cubes necessary to reduce the cyclic core resursively.

4 Description of Algorithm

Let P(C) represent the prime complex of a two-level minimization problem, initially given as a cubical complex C, let TP(C) be the graded (by dimension) covering table representing the choice pairing function Pairf(cube, prime) by a (∑ni) x |P| matrix of 0's and 1's, where P is the cubical complex of all prime cubes of C, and ni is the number of covering element cubes in the cover of dimension i. In the classical Quine-McCluskey case, n0=number of vertices(minterms) of C(f).

Each cube will correspond to a row of the covering table, and each column corresponds to a prime cube of the cubical complex, which lives in a universe which is the smallest dimensional cube containing all the cubes of the cubical complex.

The graded table is a view of the Abstract Cell Complex, but is not equivalent to the information in the abstract cell complex.

The covering problem is to find a minimum set of columns of TC which cover C, and has minimal cost.

The new contribution of this paper is two-fold: to introduce cell complexes as a natural representation of combinatorial problems, and to show how this representation allows the introduction of a new reduction method during the cyclic-core recursive solution.

4.1 Finding a collapsible cell.

With the representation we have chosen, finding collapsible cubes is like finding essential cubes. Consider a top dimensional cube c, of dimension k. Then a cube with a free face is one where the set of k-dimensional cubes intersected with c does not cover c. The faces of c not covered by intersecting all the top-dimensional cells, with a chosen cell, and the free faces are those not covered by the 1-less dimensional faces. Note that this is the first step in the classical Quine-McCluskey algorithm.

4.2 Collapsible Element Reduction

Given an implicit or explicit representation of the initial cubical complex, we allow the addition of cells to the complex, when necessary, to solve the covering problem. Most additions result from intersecting cells when computing the set of primes or finding the collapsible cells.

Theorem 7. The [CyclicCore] step of Theorem 6 can be replaced by the [CyclicCoreCollapse] step, and maintain cover cost minimality.

[CyclicCoreCollapse] If a collapsible element exists, removing the element p, and replace it with the set of free faces of p, perform a single recursive call of the modified minimization algorithm, if any of the added faces are in the returned cover, remove them, and add p back in. If there are no collapsible faces, perform the [CyclicCore] step of Theorem 6.

Proof

□

This involves, at the covering matrix level, removing the column p, and replacing it with the set of one dimensional less columns which are the free faces of FreeFaces(p).

Recursively continue to apply the non cyclic-core reductions, followed by the cyclic-core collapsible reduction, along with chosing a face of the the most recently used collapsible cube processed when a sub cyclic core has no collapsible cubes in it, and return with a cover CollapseCov.

Claim: CollapseCov, or CollapseCovPlus = ReducedCov(CollapseCov + p) is the absolute minimum cost cover of the row elements by the column sets, where ReducedCov simply takes a cover and makes it irredundant.

Let FreeSize = |CollapseCov ∧FreeFaces(p)|. To complete the proof, consider the following cases:

  1. FreeSize = 0 ,

    If FreeSize = 0 , then CollapseCov is the minimum, as it didn't use any of the added cells, hence only used the original cells to cover the rows, and, so corresponds to the case that the cube was not included initially.

  2. FreeSize ⩾ 1,

    Then CollapseCovPlus is the minimum, as the expansion of the cube in the direction of one of the free faces returned keeps the cost the same, or better, if the cost function is dimension dependent. Then CollapseCovPlus is the minimum, and will have a cost less than or equal to the cost of CollapseCov, as if all the returned faces are removed, we have a minimum cover of the original Cyclic Core by primes, which can be at most one less element in cost from the case when the cube is originally included in the minimal cover, and then minimized. This returned encoding corresponds to having the original cube p in the minimal cover.

5 Realization Considerations

State of the art unate covering tools is embodied in the tools UNC, Aura-II, Scherzo, and Espresso-Signature-Exact. To implement the concepts in this paper, the techniques should be added to one of the above code bases, and compared to the others on suites of examples, as was done in UNC and Aura-II.

It is an open question as to whether the proof given in this paper can be extended to the case of encoding all of the collapsible cubes simultaneously, as a single step, and then continuing with the algorithm recursively. This type of operation would correspond to shelling the cyclic core by collapsing it's boundary all at once, and then recursively continuing with that process.

6 Conclusions

In this paper, it was shown first, how to identify special cubes, called collapsible ones, in the cyclic core covering problem, and second how to use them to modify the branch part of the branch and bound algorithm, which allows a minimum cost solution to be found with a single recursion, at the cost of encoding the collapsible cubes by their free faces, and by maintaining the structure of the cubical cell complex, as the minimization proceeds.

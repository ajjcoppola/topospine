The Abstract Cell Complex Covering Table

Alan J. Coppola and Richard Weiss

The Evergreen State College

Olympia, WA 98005

Abstract

The minimal cover problem is generalized to abstract cell complexes, and a new covering table operation is defined, which applies to solving the cyclic-core subproblem at the recursive branch and bound stage of the classical minimum covering algorithm. It is shown how the introduction of the concepts of cell collapse and expansion from simple homotopy theory are used to reduce the number of recursive computations needed to solve the minimal covering problem. Connections to classical two-level logic minimization covering tables are given.

3 Abstract Cell Complex

An abstract cell complex generalizes the representation of a structure in which to represent minimal covering problems, higher-order connectivity, cycles of any dimension, and geometric visualization of optimization problems.

Definition 1. An abstract cell complex C consists of:

  • A set S
  • A collection Skel of finite subsets of S, each called a cell of C
  • A closure under intersection property for Skel (if a, b ε Skel, then a ∧b ϵ Skel)
  • A face and boundary operator
□

Definition 2.
Let C be and abstract cell complex. Let c be a cell of C. c is said to be collapsible if c has a free face f ε ∂c, such that f ⪰ c, and f ⪯̸ q for all q ε C.
□

4 Minimization Process

An abstract cell complex can be used to represent a variety of problems. For example:

  1. Two-Level Boolean Logic Minimization, where each cell is an n-cube, and a collection of n-cubes represents the ON-set of a boolean function f.
  2. Multi-Valued Logic Minimization, where each cell is an m 1 x m 2 x ... x m k - hedron.
  3. Deadlock complexes
  4. Programs as fixed-points

4.1 Exact Two-Level Boolean Minimization

The object of this classical problem is given a boolean function f, find an exact minimum size representation of f as a sum-of-products cube representation of f. The usual algorithm is to

  1. Find all the prime implicants of f
  2. Create the covering matrix of the primes of f, where the columns are the primes and the rows are the minterms of f.

  3. Perform reductions on the covering matrix, until a fixed point table, called the cyclic-core is reached. The table reductions are:

    1. Essentials reduction
    2. Row dominance - a strongly equivalent operation
    3. Column dominance - a weakly equivalent operation
  4. Recursively solve the cyclic-core problem by choosing a column(prime) to assume is first in the cover, find a recursive solution, and then is not in the cover, find a recursive solution to that problem, and then pick the cover that has the least number of elements as the minimal cover. Sophisticated branch and bound techniques, involving choosing a maximal independent set of elements at each cyclic-core recursion can be used to create a series of lower bounds on which to prune the recursions.

5 Description of Algorithm

Given the representation of a problem as an abstract cell complex C, let TC be the graded(by dimension)) covering table represented by a (∑ni x P) matrix of 0's and 1's, where P is the number of elements in the cover, and ni is the number of elements of dimension i.

The covering problem is to find a minimum set of columns of TC which cover C, and has minimal cost.

The new contribution of this paper is two-fold: to introduce abstract cell complexes as a natural representation of combinatorial problems, and to show how this representation allows the introduction of a new reduction method during the cyclic-core recursive solution.

5.1 Collapsible Element Reduction

Theorem 3. Given a collapsible element p in a graded covering matrix, which is a cyclic-core, remove the element p, and replace it with the set of free faces of p. Then one recursive call is all that is necessary to find the minimum cost cover of TC.

Proof

□

This involves, at the covering matrix level, removing the column p, and replacing it with the set of one dimensional less columns which are the free faces of FreeFaces(p).

Recursively continue to apply the non cyclic-core reductions, followed by the cyclic-core collapsible reduction, and return with a cover MinCov. Let FreeSize = |MinCov ∧FreeFaces(p)|. If FreeSize ⩾ 1 , then put back in p to get the minimum cover. If FreeSize = 0 , then MinCov is the minimum, as it's size will at most be one less than the minimum with the element p not included
